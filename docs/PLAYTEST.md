# EMBERWHEEL — 自律プレイテストと改善ログ

## 0. 方法
- **ヘッドレス・シミュレーション**（`tools/sim.js`）: 実エンジンを使うボット（Spinのみ／貪欲に介入する“上手い”ボット／介入しないボット）で Run 1、ボス戦、キャンペーンを数千回回して数値を検証。時間は演出待ち＋人間の思考時間＋画面遷移を含む現実的モデルで見積もり。
- **エンジン・ファズ**（`tools/fuzz.js`）: 灯紋をランダムに組み合わせ、合法手をランダムに選び続けて不変条件（HP/火種/リール位置/予測と実際のダメージの一致など）を検査。最終 5,000 Run / 0 failures。
- **ブラウザ実機プレイ**: 実ブラウザで Run 1→死亡→野営地→Run 2… を通しで操作し、全画面をキャプチャして確認。UI 層のソーク（全灯紋解放・ランダム操作・高速）でランタイムエラー 0。
- **5視点の並列レビュー**（各エージェントが独立に実施）:
  1. 新規プレイヤー（実ブラウザ・初期セーブから4 Run）
  2. 中盤プレイヤー（実ブラウザ・中盤セーブから3 Run、ボス戦含む）
  3. アートディレクター（全画面・全状態をキャプチャ）
  4. システム分析（Node で 30 本以上の実験スクリプト、各条件 N=400〜1200）
  5. コードレビュー（13件中 8件を Node で再現確認）

## 1. 設計段階のレビュー（実装前・Monte Carlo）→ 変更（v0.2）
| 問題 | 変更 |
|---|---|
| Run 1 の鐘つき犬に Spinだけで 99% 勝ててしまい「あと少し」が起きない | 一行HP 32、犬 HP72・噛みつき6・鐘撃21、第一層の攻撃+1 |
| 最初の解放（全リール再演）が結果をほとんど変えない | 最初の灯紋を【押し手（ずらし）】に（Run 1 のニアミス表示に直接答える） |
| 介入資源（火種）が少なく大半のターンが自動 | 灯で火種+1（1ターン1回）、三連/絆で火種+1 |
| 無順序の絆＋ずらしが唯一解、ボスが1ノードで解ける | 絆を「各自のリールに各自の目」の**順序付き陣形**に |
| 第四輪がランダム性を増やし終盤を運任せに | 削除し、運の頂点を【運命の鍵】に |

## 3. Phase 10 — 5視点レビューの主な発見
**新規プレイヤー**: Run 1 は鐘つき犬の残りHP 2/72 で倒れ、死亡画面の「1コマずらせば三連になった目が5回」→【押し手】を灯して再挑戦、が最も強い動機になった。Run 3 で犬をずらしで撃破、Run 4 で留め＋再演＋ずらしを使いこなす。「あと1回」は Run 2 で発生。課題: 最初の灯紋の推奨が画面ごとに割れる（研ぎ vs 押し手）、殻ムシ戦が Spin のみで15ターン超かかることがある、留めの印が「盾」に見える、など。
**中盤プレイヤー**: ボスを3回とも初挑戦で撃破。封印は3ターンで割れ、以後は HP の殴り合い。第二/第三層の敵が1〜3ターンで溶ける。継ぎ留めの「1ターン限り」が付け外しで無限化。遅い段階の死亡画面のささやきが汎用文になる。
**アートディレクター**: 世界観と装置の絵は強い。課題は階層とヒエラルキー（チュートリアル吹き出しが発動列を隠す、致命的な予告が目立たない、予測パネルが溢れる、バナーが重なる、背景小物が演技レーンで明るすぎる、下部帯が平板、遺物が漢字のみ、など14件）。
**システム分析**: 介入なしのボットでも 17ノードで31%勝てる（封印が技術の関門になっていない）。精通の灯紋がクリア時点でほぼ未購入。再演が火種の罠（貪欲に使うと勝率が下がる）。連鎖/灯守り/起死回生/樫の小盾/吸血の牙が突出、灰燼は数学的に損。
**コードレビュー**: 怨念の扉の直後の連打で進行不能、ボスの段階移行で予告と違う行動、B5 即あきらめで残り火稼ぎ、反射込みでない被ダメ予測、封じられた記号の三連率を表示、など13件。

## 4. Phase 11 — ゲームデザインの変更（v0.3）
| 問題 | 変更 | 検証結果 |
|---|---|---|
| ボスが数値の殴り合い | HP420、**封印中は毎ターン加速**、燃焼/反射は封印越しに50% | 介入しないボット: 17ノード 31%→0%、25ノード 74%→1%。介入するボット: 17ノード24%、精通25ノード94% |
| 精通の灯紋が買われない | 写し身120・運命の鍵170・連鎖160・灯守り150・守護110、写し身/鍵は火種1・1ターン1回 | キャンペーンのクリア時点で頂点の灯紋を所持（例: 運=写し身/鍵、猛=連鎖） |
| 再演が火種の罠 | 各戦闘の最初の再演は無料 | 再演の取得が勝率を下げる現象が解消 |
| 突出した灯紋・遺物 | 連鎖2ターンに1回、灯守り10%、起死回生15%、精妙×1.5、小盾2、牙10%、帽子の蝋は燃焼上限12、灰燼は燃焼を消費しない、守護は「盾2つ以上で受けた攻撃を全反射」 | 運/猛/守のボス勝率差が縮小（運22%・猛37%・守24%、ボットの計画性不足込み） |
| 第二/第三層・エリートが溶ける | HP 引き上げ（例: 修道院長130→160、ゴーレム75→88） | 中盤の戦闘が2〜4ターンに |
| 最初の灯紋の推奨が割れる | `recommendedNode` に一本化（新しい動詞を優先、死亡画面のささやきを野営地に引き継ぐ） | Run中トラッカー・野営地・死亡画面が全て【押し手】を指す |
| 殻ムシで Run 1 が停滞 | 剣で打つたびに鎧が割れる、丸まりは3ターンに1回 | Spinのみで中央値5ターン・p95 9ターン |
| 継ぎ留めの無限化 | 持ち越しは1ターン限り（付け外しでも再持ち越し不可） | ファズで不変条件確認 |
| 灯の価値が終盤で消える | 灯の残り火は深いほど増える | 灯を削るかの葛藤が終盤も残る |
| 2体目のエリートを倒しても報酬がない | 修道院長を一度倒すと、B5 近道で選べる遺物が+1 | 死亡画面にチップで表示 |
| **全体のテンポ** | 残り火×0.85 | 上手いボットで 8〜9 Run・約32〜38分（人間は40〜55分想定）。全戦略（運/猛/守/均等/ランダム）がクリア可能 |

## 5. Phase 12 — ビジュアルとゲームフィールの改善
- 予告の格上げ: 溜めの予告に次の強撃の値（「咆哮 → 次は鐘撃 21」）、致命の攻撃は大きく赤い「致命」タブ、パーティHPバーに予測ダメージの斜線。
- 光のヒエラルキー: 背景を一段落とす舞台照明、灯輪からのフットライト、下部帯を木の舞台前縁（エプロン）に。
- 盤面: 三連時の発動列の光の掃き、舞台全体が暖色に灯る歓喜、火種の蝋燭を大きく（棚＋残数＋使う分の点滅）。
- UI: 真鍮縁の石板に統一、数字にインク縁、バナーの重なり防止、目覚めのヒントは盤面の外に、モーダル中は下地を暗く＋一行の様子（HP・火種・各リールの構成）を表示、予測パネルの溢れ解消（確率は右列へ）、運命の鍵/遠押し用の大きなコマ選択パネル、写し身のホバー予測。
- 野営地: 外周を広げて重なり解消、推奨ノードだけ脈動、コスト表示を最前面のピルに、系統ラベルを札に。
- 留めの印を盾（盾シンボルと誤読）から真鍮の南京錠＋ブラムの赤い房に。
- リールと舞台の並びを一致（左からトト・ルゥ・ブラム＝リール1/2/3）、絆の陣もその順に。
- 遺物・出来事の挿絵（漢字のみの仮表示を置き換え）。
