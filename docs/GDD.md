# EMBERWHEEL ― 灯輪(ともしわ)と深淵 ― Game Design Document (v0.2)

> Run-based Incremental Slot Dungeon RPG。
> 「最初は運に翻弄されていたプレイヤーが、最後には自分で運命を組み立てている」

v0.2 = 4視点の敵対的レビュー（Monte Carlo検証付き）を反映した改訂版。変更点は §12 に要約。

---

## 0. 一文説明
三人の小さな探索者が、古代の運命装置「灯輪(ともしわ)」を回して深淵へ挑む。
死ぬたびに残り火(Ember)を持ち帰り、灯輪に**灯紋(ともしもん)**を灯して、
**"祈るだけのスロット"を"自分で組み立てる運命"へ育てていく**ゲーム。

用語: **灯紋** = 恒久スキル（灯輪ツリー・金縁）／**刻印** = Run中のリール改造（石色）。

## 1. Core Experience

### 1.1 なぜもう1Runしたくなるのか
1. **見えている惜しさ**: 盤面は発動列（中央段）だけでなく上下の段も見える。各リール横の**帯（ストリップ・リボン）**で、リールの中身全部も常に見える。
   「1コマずれていれば三連」が約24%のスピンで光る（ニアミス）。
2. **最初の灯紋がその惜しさに直接答える**: 最初に灯せるのは【押し手（ずらし）】。Run 1中に一度だけ「灯輪の目覚め」でずらしを無料体験させる。
3. **死亡画面は"1つの後悔 → 1つの灯紋 → 1キー"**: 惜しかった敵のHPバー（あと○○）、持ち帰った残り火、そして運命のささやき1行（このRunの実データ）とそれを解決する灯紋カード。[灯して再挑戦]。
4. **灯紋の多くは"新しい動詞"**: ずらし／再演と留め／写し身／継ぎ留め／運命の鍵／絆の陣／祝福…。
5. **短いRun**: Run 1 ≈ 2分。エリート/ボス撃破で次から深層スタート（ショートカット）。

### 1.2 最初の5分
- レバーを引く→3つの石の円筒が回る→1つずつ「ゴトン」。結果が三連/ニアミスの時だけ3本目が**溜め**て止まる。
- 剣→ブラムが斬る、焔→ルゥが火球、癒→トトが祈る、盾→ブラムが構える。三連は画面全体が喜ぶ。
- 戦闘後の**分かれ道画面**: 刻印3択（リールを彫る）＋次の扉。
- B4のエリート「鐘つき犬」で約8割が倒れる（残りHP 2〜3割）→「あと少し」。
- 帰還→【押し手】を灯す→次のRunで光ったマスを押せる。

### 1.3 20分後に何が変わるか
- ずらし・再演・留めで**狙って三連/絆を作る**。敵の予告を見て「盾が欲しい」「焔が欲しい」「封じの目を外す」。
- 火種の使い方（今か、ボスまで温存か）。リール構成（確率空間）の設計。危険な扉をビルド次第で"おいしい"と判断。

### 1.4 スロットを除いたら成立するか？ → しない
行動は全て発動列から生まれ、判断は全て**スロットへの介入**と**確率空間の編集**。敵の多くはスロットへ干渉（髑髏混入・固着・封じ・吸火・反射）。ボスは三連/絆でしか割れない封印を持つ。

### 1.5 固有の気持ちよさ
「惜しい！」を自分の手で「揃った！」に変える瞬間。自分で彫ったリールが狙い通りに回る手応え。予告と盤面を照らし合わせて"このターンの正解の目"を組み立てる詰将棋感。

### 1.6 差別化
成長対象がステータスではなく**確率空間と介入手段**。敗北データから**具体的な後悔**を算出し、次の灯紋と直結させる。

## 2. 世界観（文章は最小限）
- 地の底で「灰輪の主」が逆さに廻る。灯輪（三つの石の円筒を真鍮枠に収めた運命装置）を持つ者だけが深淵へ降りられる。
- 倒れた探索者の魂は残り火として地上の野営地の灯輪へ戻る。残り火で灯紋を灯す。
- **ブラム（騎士）** 担当: 剣・盾／リール3。バケツ兜に赤い羽根。リールを"留める"。
- **ルゥ（魔女）** 担当: 焔／リール2。巨大なとんがり帽子の先に蝋燭。リールを"再演"・"写し身"。
- **トト（僧）** 担当: 癒／リール1。丸い修道僧、香炉ランタン。リールを"ずらす"・"祝福"。
- 舞台の並び（左からトト・ルゥ・ブラム）＝リール1/2/3。**各自の目が各自のリールに揃うと「絆の陣」**。

## 3. Runの構造
```
野営地(灯紋ツリー) → 降下 → 部屋 → 分かれ道画面(刻印3択＋次の扉) → 部屋 → … → 死亡 or ボス撃破
```
- 第一層「蝋燭の地下蔵」B1–B3 通常 / B4 エリート「鐘つき犬」
- 第二層「水没した納骨堂」B5–B7 通常/イベント / B8 エリート「骨の修道院長」
- 第三層「歯車の深淵」B9–B11 通常/イベント / B12 ボス「灰輪の主」
- **ショートカット（無料の節目）**: 鐘つき犬を一度倒すとB5から降下可能。スキップ分の刻印3回＋遺物1を開始時に選び、残り火+25は最初の勝利で得る（即あきらめで稼げない）。
  （B9ショートカットはボス連戦化とRunの短縮を招いたため不採用。）
- 扉: Run 1は一本道（次の部屋が1つ見えるだけ）。Run 2〜は「戦い / 怨念の敵」、Run 3〜は祭壇、焚き火（灯紋）も混ざる。
- **分かれ道画面**: 戦闘勝利後、刻印3択（スキップ可）と次の扉を同じ画面で選ぶ。クリック数を最小化。

### 3.1 扉（Risk & Reward）
| 扉 | 内容 | 報酬 |
|---|---|---|
| 戦い | 通常戦（扉に敵が見える）| 刻印3択 |
| 怨念の敵 | HP×1.5・攻撃×1.5・戦闘中リール1本に髑髏1 | **遺物**3択 + 残り火×2 |
| 祭壇 | イベント | 内容次第 |
| 焚き火（灯紋）| HP35%回復 or 鑿（1つ削る）| — |

### 3.2 イベント
血の祭壇（HP12→最大火種+1・全回復）／呪われた宝箱（遺物＋全リールに髑髏1：髑髏の契約があれば得）／運命の賽銭（1リール運試し）／刻み師の幽霊（2つ削る or 1つ複製）／古い宝箱（ミミック戦→遺物）。

## 4. スロット
### 4.1 構造
- リール3本、各リールは**ストリップ**（初期10コマ、同構成・異なる並び・同じ記号が隣接しない）。
- 初期構成: 剣×3 / 盾×2 / 焔×2 / 癒×2 / 灯×1。
- 表示3段。中央段＝**発動列**。各リール右に全ストリップの**リボン**（現在の窓をブラケット表示）。

### 4.2 シンボル（基礎効果は1個あたり）
| ID | 名 | 効果 | 三連 |
|---|---|---|---|
| blade 剣 | ブラム | 4ダメージ（敵の鎧でグループ合計から減る）| 断罪: 鎧無視 |
| flame 焔 | ルゥ | 3ダメージ（鎧無視）| 業火: 燃焼+4 |
| ward 盾 | ブラム | ブロック4 | 城壁: 次の敵の攻撃の50%を反射 |
| heart 癒 | トト | 回復3 | 聖域: 混入した髑髏を全て浄化 |
| lantern 灯 | ― | 残り火+2、**火種+1（1ターン1回）**| 大当り: 残り火+20 |
| skull 髑髏 | 呪い | 自分に3ダメージ（ブロック無視、HP1未満にはならない）| 死神: 敵に30（鎧・封印・ブロック無視）|
| wild 星 | ― | 発動結果が最大になる記号に化ける（プレビューに表示）| ― |

**一致倍率**: 効果 = 基礎 × (個数+金箔数) × M(個数)。M(1)=1, M(2)=1.5, M(3)=2.5。 → 三連は単発の7.5倍。
金箔: その1個の効果を2倍に数える。

### 4.3 コンボ
- **三連**: 同じ記号3つ。
- **絆の陣（灯紋）**: リール1=癒（トト）・リール2=焔（ルゥ）・リール3=剣（ブラム）（各自の目が各自のリールに）。三人の効果がそれぞれ×3、ボスの封印を割る。星も1か所を埋められる。
- **死神**: 髑髏三連。
- 三連・絆を出すと**火種+1**（上限まで）。

### 4.4 介入（段階解放）
| 操作 | 解放 | コスト | 操作方法 |
|---|---|---|---|
| SPIN | 最初 | 無料 | レバー / Space |
| ずらし | 灯紋【押し手】| 火種1 | 上下段のマスをクリック（ホバーで結果をプレビュー）|
| 再演 | 灯紋【再演と留め】| 火種1 | 再演ボタン / R |
| 留め（2本まで）| 同上 | 無料 | リール下の留め金タブ / 1・2・3キー |
| 遠押し（2コマ）| 灯紋【遠押し】| 火種1 | リボンの±2コマをクリック |
| 継ぎ留め | 灯紋 | 無料 | 最後に留めた1本が次ターンも留まる（1ターン限り）|
| 祝福 | 灯紋 | 1戦1回無料 | 発動列の髑髏をクリック→癒 |
| 写し身 | 灯紋 | 火種1・1ターン1回 | 写し身ボタン→元のマス→先のマス（ホバーで結果をプレビュー）|
| 運命の鍵 | 灯紋（運の頂点）| 火種1・1ターン1回 | 鍵ボタン→リールを押す→コマ選択パネルから選ぶ |

- **火種**: Run開始時 2（上限3、火種壺で4）。戦闘勝利+1、灯+1（1ターン1回）、三連/絆+1（灯の三連を除く）。各戦闘の最初の再演は無料。蝋燭（残数と、操作にかかる分の点滅）で表示。
- **発動**: 介入可能なときはプレビュー（与ダメ→敵HP、被ダメ予測、回復、コンボ）を出して待つ。Space/レバー＝発動。
  介入不可能・または結果が既に三連/絆・または敵を倒せる場合は短い間(0.35s)の後に自動発動。
- **ニアミス**: 1リールを1コマずらせば三連（絆解放後は絆も）になるマスだけ光る＋小さな矢印。

### 4.5 確率空間の成長
- **刻印（Run中）**: 追加（リールNに記号を彫る）／変換／削除／鑿（好きなコマを削る）／金箔／回復／火種上限+1。
  選択時、そのリールの各記号の出現率の変化（剣 30%→36%）と「三連率」の変化を表示。
- **灯紋（恒久）**: 新しい操作、新しいコンボ、部屋、初期ストリップ改造（星・鑿）。

## 5. 戦闘
### 5.1 ターン
予告表示 → SPIN →（介入）→ 発動 → 敵の行動 → 次の予告。
解決順: 封印判定 → 盾 → 癒 → 自傷（髑髏/封じ）→ 剣/焔/死神 → 反射の構え → 灯/火種 → 燃焼付与。
敵ターン: 燃焼ダメージ → 予告の行動 → 次の予告。ブロックはターン開始時0（蓄えで持ち越し）。

### 5.2 予告
| 種類 | タイミング | 欲しい目 |
|---|---|---|
| 攻撃N | 発動後 | 盾 / 速攻 |
| 溜め→強撃N | 溜めターン中に**盾2つ以上で怯ませて中断**できる。強撃ターンは盾で受ける | 盾 |
| 防御N | 発動後（次ターン敵がブロックN）| 燃焼・死神・三連 |
| 丸まり | このターン 鎧+6 | 焔 |
| 成長 | 攻撃後に攻撃力+1 | 速攻 |
| 呪い | リールに髑髏（この戦闘中）| 速攻・聖域・祝福 |
| 吸火 | 火種-1（無ければ攻撃）| 先に使う |
| 渇き | このターン癒の回復0 | 回復に頼らない |
| 固着 | 次ターン、リール1本が操作不可 | 他で組む |
| 封じ（記号）| このターンその記号は消え、1つにつき自分に2ダメ。**最も多く彫られている記号**を狙う | ずらし・再演で外す / 偏らせない |
| 反射の構え | このターン与ダメの50%が返る（ブロックで受けられる）| 盾/癒のターンにする |
| 破滅の秒読み | 3→2→1→灰燼 | 盾 or 削り切る |

### 5.3 敵（数値はシミュレーションで調整。data.jsが正）
第一層: 燭ネズミ（攻撃4/5、溜め→噛みつき9）／澱スライム（攻撃3、毎回+1）／殻ムシ（鎧3、攻撃6/丸まり）／**鐘つき犬**（噛みつき7,7→咆哮→鐘撃22）。
第二層: 呪い蛾（呪い/攻撃）／骸骨衛兵（鎧2、攻撃/防御/溜め→強撃）／吸い火（吸火/渇き/攻撃）／**骨の修道院長**（封じ・断罪・呪詛・蘇生）。
第三層: 歯車ゴーレム（鎧6、固着）／影の写し身（反射の構え）／深淵の衛兵。イベント: ミミック。

### 5.4 ボス「灰輪の主」
- **第一段階 三つの封印**: HP420。封印が残る間、直接ダメージ25%、燃焼・棘・反射は50%。三連・絆で1つ割れる（死神+髑髏の契約なら全て）。**封印が残る間、灰輪は毎ターン加速（攻撃+1/ターン）**するため、封印の陰で削り続ける戦法は成立しない。
- **第二段階 逆廻り**: 封じが 剣→焔→盾→癒 の固定順で巡る（次の封じも見える）＋攻撃。
- **第三段階（HP30%以下）破滅の秒読み**: 3→2→1→灰燼（大ダメージ）。
- 段階移行で火種+1。検証値（上手いボット）: 介入なしでは25ノードでも≈1%、標準的な17ノード≈24%、精通ビルド（25ノード）≈94%。

## 7. 灯紋ツリー（data.jsが正）
円形（灯輪の裏面）。中心=灯輪。三区画: **運（操作・紫金）／猛（火力とコンボ・紅）／守（生存・翠）**＋橋渡し。
霧: 灯した灯紋と、そこから届く灯紋だけが見え、その先は輪郭のみ。

- 運: 押し手 → 再演と留め → 手慣れ → 遠押し → 継ぎ留め → 写し身 → 運命の鍵 ／ 火種壺 → 星の欠片・鑿
- 猛: 研ぎ → 絆の陣 → 追撃・処刑人 → 双の誓い → 三連の極意 → 連鎖 ／ 燎原 → 灰燼・髑髏の契約
- 守: 厚き外套 → 焚き火・棘の盾 → 祝福・起死回生・蓄え → 背水・不屈 → 守護の誓い → 灯守り
- 橋: 分かれ道 / 血の代価 / 祈りの手 / 賭博師の目
ボスの封印の割り方が三系統それぞれにある（運=狙った三連・鍵 / 猛=絆・燃焼・死神 / 守=棘・守護の反射・長期戦）。

## 9. アートディレクション「灯火の切り絵劇場」
- **一つの虚構**: 全ては玩具の劇場の舞台に立つ切り絵。舞台（上部）は**額縁（プロセニアム）＋幕の垂れ**で縁取る。灯輪は舞台の"フットライト"。
- 光源は一つ（灯輪＝下中央）。キャラは太いインク輪郭＋フラット塗り＋影1段。背景の書き割りは低彩度・低明度で記号色を使わない。
- 記号の色は予約色（剣=鋼白、焔=橙、盾=空色、癒=翠、灯=金、髑髏=紫、星=白）。背景で高明度に使わない。
- 遷移は舞台仕掛け: Run開始で幕が上がり、全滅で**幕が下りて死亡画面は幕に印刷**される。ボス登場は書き割りが畳まれる。
- フォント: 見出し Kaisei Decol、UI/数字 Zen Maru Gothic（Google Fonts、システムフォールバック）。数字は太いインク縁取り。
- テンポ: リール停止 0.45/0.60/0.75s、非コンボ発動は三人がほぼ同時（80msずらし）、敵行動0.45s。三連1.2s・絆1.4s・封印破壊1.6s。
  入力で演出をスキップ、入力バッファ、Shift長押しで早送り。被ダメが最大HPの15%以上の時だけ画面揺れ（最大6px）。
- パレット・UIは v0.1 §9.2/9.4 を継承（art_core.js）。

## 10. チュートリアル（文章最小）
レバーのパルス → 発動列の一瞬のハイライト → 「灯輪の目覚め」（初めてのニアミスでトトの手がマスを示す: "触れる"）→ 新しい動詞は解放直後の最初の戦闘で1行ヒントとパルス。

## 11. 禁止事項
ガチャ・課金・デイリー・ログイン報酬・FOMO・放置進行なし。数値だけのツリーにしない。

## 12. v0.2 変更点（レビュー反映）
1. Run 1が鐘つき犬に99%勝てていた → 一行HP32、犬80/7/7/咆哮/22、第一層の攻撃を強化。
2. 最初の灯紋を【押し手（ずらし）】に（Run 1のニアミス表示に直接答える）。留めは最初から2本、旧「留め1本」「双つ留め」は統合。
3. 火種の収入を増加（灯で+1、三連/絆で+1）。介入が"1戦1回"にならないように。
4. 絆を**順序付き（各自のリールに各自の目）**に。無秩序な絆＋ずらしが常に最適解になる問題を解消。
5. 第四輪を削除し、運の頂点を【運命の鍵】に。星降り・金箔ノード等を整理（約35ノード）。
6. 封じは「消える＋小ダメージ」に単純化し、最も多く彫られた記号を狙う（偏りへの対抗）。
7. 燃焼・棘・守護の反射を強化し、封印を割る三系統の道を実数で成立させる。
8. 報酬と扉を1画面に統合、自動発動の条件を明確化、ストリップ・リボンとオッズ表示を追加。
9. エリート撃破でショートカット（無料）。後半Runの第一層の繰り返しを削除。
10. 死亡画面は1つの後悔→1つの灯紋→1キーに集約。

## 13. v0.3 変更点（プレイテスト後の改善・Phase 11）
5視点レビュー（実機2名・アート・システム分析・コード）の結果、「ボスが数値の殴り合い」「精通の灯紋が買われない」「再演が火種の罠」「一部の灯紋/遺物が突出」が判明。以下をまとめて変更し、シミュレーションで再検証した。
1. ボス: HP420、**封印中は毎ターン加速**、燃焼/反射は封印越しに50% → 介入なしでは勝てない（≈1%）、精通ビルドは≈94%。
2. 精通（頂点）の灯紋を安く（写し身120・運命の鍵170・連鎖160・灯守り150・守護110）。写し身/運命の鍵は火種1・1ターン1回。
3. 再演は各戦闘の最初の1回が無料（「再演は火種の罠」を解消）。
4. 突出の調整: 連鎖は2ターンに1回、灯守り10%、起死回生15%、精妙×1.5、樫の小盾2、吸血の牙10%、帽子の蝋は燃焼上限12。灰燼は燃焼を消費しない純粋な上乗せに、守護の誓いは「盾2つ以上で受けた攻撃を全反射」に作り直し。
5. 第二/第三層とエリートを強化、ミミック強化、古い宝箱は半分本物、怨念の扉はゴーレムだけ控えめ・影は出ない。通常戦の勝利で一息（HP回復）。
6. 灯の残り火は深いほど増える（灯を削るかの葛藤が終盤も残る）。継ぎ留めの持ち越しは1ターン限り（再留めで無限化しない）。
7. 遅い段階の「運命のささやき」を追加（封印が残った→写し身/鍵、強撃で倒れた→守護…）。データに基づかない時は Space で購入しない。
8. 検証: 上手いボットで8〜9 Run・現実的な時間モデルで約32〜37分（人間は40〜55分想定）、全ての戦略（運/猛/守/均等/ランダム）でクリア可能。
