## 1. コンセプト

### 1.1 正体と物語
- 三人は、運命を祈りながら灯輪を廻してきた。けれど深淵の敵も三人も、劇場の上から垂れる**糸**で動いていた。敵の行動を書いた「台本」を書いていたのも、この者。
- **深淵の繰り手**は、灯火の切り絵劇場の上に住む人形遣い。灰輪の主は、この者が逆さに廻させていた人形だった。
- 決着は「最後の三本の糸を、三人が自分の手で断つ」こと。ゲームの一文説明「運命を祈る者が、運命を自ら組み立てる」を、そのまま絵と規則にする。

### 1.2 名前
- **深淵の繰り手（しんえんのくりて）**。候補：「糸繰りの主」「劇場の主」。
- 段の名前：糸の段／面の段／終幕の段。

### 1.3 これまでとのつながり
| これまで | 最終ボスでの意味 |
|---|---|
| 灰輪の台本（帯）・台本送り | 繰り手が書いた台本。台本送りは「繰り手の手から台本を奪う」行為 |
| 灰輪の主の封じ・返し鏡の封じ | 面の段で、繰り手の面が同じ封じを使う |
| 重ね殻・灰鐘の番人の「崩す」 | 吊り上げ（溜め）を盾2つで崩す、今の規則をそのまま使う |
| 灯紋（全37） | 糸を断つ道具（ずらし・遠押し・写し身・運命の鍵・祝福・再演）と、糸を受け入れる道具（髑髏の契約・守護）の両方になる |

## 2. 戦いの設計

### 2.1 固有の問い
「繰り手は、三人のリールに糸を張り、次の目を書いておく。**その目を受け入れるか、火種を使って自分の手で組み立て直し、糸を断つか**」

- 1ターン目から糸がある（初手から問いが成立する。段階3a の教訓）。
- 挑戦する人は全員が全灯紋を持っている。そのため、強さの幅ではなく、**挑戦の中の刻印・遺物・リールの組み方**と、**火種の配分**で答えが変わるように作る。

### 2.2 規則：糸

| 規則 | 内容 |
|---|---|
| 糸を張る（予告） | 繰り手の台本の各コマに「糸：リール2を髑髏に」のような指示が付く。帯で先まで読める |
| 引く | 回したとき、糸の張られたリールは回らず、発動列が指示の目になる（リールの中身は変わらない。写し身と同じ「上書き」） |
| 断つ | 糸の張られたリールを、自分の操作で動かすと糸が切れる。使える操作はずらし・遠押し・運命の鍵・写し身（そのリールへ写す）・祝福（髑髏のとき）・再演（そのリールを留めずに回し直す）。費用は今と同じ（火種など） |
| 断った手応え | 糸を1本断つごとに、繰り手に「糸の反動」ダメージ（初期案 20）。断った糸は、そのターンの間は張り直されない |
| 受け入れる | 断たなければ、引かれた目は普通の目として働く。髑髏なら自分が傷つく。ただし**髑髏の契約**なら敵に当たり、髑髏が3つ揃えば**死神**になる（呪いの活用） |
| 三本断ち | 1ターンに3本の糸をすべて断つと「三本断ち」。繰り手はそのターンの行動を失い（怯み）、大きな反動を受ける（初期案 80）。終幕の秒読みも戻る（§2.3） |

- 予測＝実際：糸の目・断ったときの反動・三本断ちは、予測パネルと帯に確定値で出す（今の作り方のまま、複製で計算し、乱数は使わない）。
- 帯の表示：コマの右上に、糸の本数と引く目を出す（例：「糸2：①髑髏 ③灯」）。

### 2.3 三つの段と台本（初期案）

| 段 | HP の範囲 | 糸 | 主な行動 | 新しく加わるもの |
|---|---|---|---|---|
| **糸の段** | 100%〜60% | 1本／ターン（リール1→2→3の順に張る） | 糸引き（攻撃＋糸）、吊り上げ（溜め：次は「落とし」。盾2つで崩れる）、落とし（強撃） | 糸の規則を覚える段 |
| **面の段** | 60%〜30% | 2本／ターン | 上に加えて、面の**封じ**（返し鏡と同じ。前の発動の主役の記号を封じる） | 幕の垂れが落ち、面が全身を現す |
| **終幕の段** | 30%〜0 | 3本／ターン（全リール） | **終幕の秒読み**：3 → 2 → 1 → 「終幕」（大技）。三本断ちで秒読みが3に戻る | 劇場の額縁が崩れ始める |

**糸の段の台本（4コマの周期、初期案）**

| コマ | 行動 | 糸 |
|---|---|---|
| 1 | 糸引き：攻撃 18 | リールAを髑髏に |
| 2 | 手繰り：攻撃 12、火種を1つ奪う | リールAを灯に |
| 3 | 吊り上げ（次は「落とし」42。盾2つで崩れる） | リールAを盾以外に（盾を2つ揃えにくくする） |
| 4 | 落とし 42（溜め終えた一撃。台本送り不可） | なし |

- 引く目は、コマごとに決まっていて帯で読める。髑髏（害）、灯（弱い目）、主役の記号を外す（盾など）を混ぜる。プレイヤーに「受け入れても痛くない糸」と「必ず断ちたい糸」を見比べさせる。
- 段が変わるとき、火種+1（灰輪の主と同じ）。

### 2.4 勝ち筋（ロードマップ §5.5 の6つの型）

| 型 | この戦いでの答え方 |
|---|---|
| 金剣などの高火力 | 糸のない2本で三連を作り、写し身・鍵で3本目を取り返して一気に削る |
| 燃焼・起爆 | 燃焼は糸に関係なく効く。糸を受け入れて火種を節約し、燃焼で削り続ける |
| 盾・守護・反射 | 落とし・終幕を守護の誓いで跳ね返す。吊り上げは盾2つで崩す |
| リール操作と台本送り | 糸を断つ主役。台本送りで「3本の糸のコマ」を先に送り、糸の少ないコマを呼ぶ |
| 呪いの活用 | 髑髏の契約で、髑髏の糸をそのまま攻撃に変える。終幕の段で髑髏3本＝死神 |
| 火種の管理と借り火 | 三本断ちには火種が足りない。借り火と、手慣れ（最初のずらし無料）、割れた鏡などを組み合わせる |

- どの型も、全部の能力を使う必要はない（ロードマップ §5.5）。

### 2.5 数値の方針と目標（G4 で決め、4b で sim で確かめる）

| 指標 | 目標案 |
|---|---|
| 1回の挑戦の勝率（全灯紋・上手なボット） | 50〜70%（B16 から続けた場合）。キャンプの入口は支度を調整して同程度 |
| 決着までのターン数 | 中央値 9〜13 |
| 初手撃破 | 0%（上手な操作のモデルでも） |
| 型（方針×彫り方）による勝率の差 | 25pt 以内 |
| 糸の扱い | 勝った戦いで、糸を「断つ」と「受け入れる」の両方が使われている（どちらかに偏りすぎない）。三本断ちが勝った戦いの半分以上で起きる |
| HP | 初期案 1600（段の境は 60%・30%）。高HPで長くするのではなく、糸の税で長さを作る |

### 2.6 実装の見通し（4b）
- エンジン：リールに「引かれた目」（写し身と同じ上書き）を足す。糸の張り・断ち・反動・三本断ち・段の切り替え（灰輪の主と同じ仕組み）・終幕の秒読み（破滅の秒読みと同じ仕組み）。
- 予測・帯・ボットの評価に糸を入れる。B1〜B16 の挙動は変えない（今の回帰・sim 出力の一致で確かめる）。
- **4b の最初に、試作で数値を測る**（段階3a・3b と同じ方法）。目標から大きく外れたら、規則の数（糸の本数・反動）を見直して、もう一度ユーザーに相談する。

## 3. 見た目

### 3.1 繰り手
| 部分 | 描き方 |
|---|---|
| 手 | 幕の垂れの奥から降りる、二本の紙の大きな手。指は関節ごとに真鍮の鋲で留めた切り絵。袖は深い紫、袖口に金の縁 |
| 糸 | 操り板から三人の頭と灯輪へ伸びる金の糸。光るのは糸だけ（加算の光は灯りと糸に限る。今の作法どおり） |
| 面 | ひびに金を継いだ紙の面（能面に近い穏やかな顔）。目は紫に光る。段が進むと、ひびが広がる |
| 胴（面の段から） | 黒い紙を重ねた着物の切り絵。袖の裏に、これまでの敵（灰輪の主・修道院長・番人）の小さな人形が吊られている |

**動き（ポーズ）**：待機（指がゆっくり糸を手繰る）／糸を張る（指を弾く・糸が光って伸びる）／吊り上げ（両手を高く上げる）／落とし（両手を叩きつける）／怯み（手が跳ね上がる）／倒れる（糸が順に切れ、手が落ち、面が割れる）。

### 3.2 最深の間（背景）
- 「灯火の切り絵劇場」の**舞台裏**。吊り物の綱・滑車・砂袋・立てかけた書き割り・空っぽの大きな舞台。中央に一つだけ吊りランプ。
- 段の変化：
  - **糸の段**：舞台裏の暗がり。綱が揺れている。
  - **面の段**：上の幕の垂れ（ゲーム画面上部の飾り）が落ち、面が現れる。
  - **終幕の段**：奥の書き割りが裂け、深淵と逆さに廻る灰輪の影が見える。額縁（左右の柱）にひびが入り、紙片が舞い落ちる。

### 3.3 三人
- 戦いの間、三人の頭上に金の糸が付いている（断つとその人の糸が弾けて消える）。三人の絵そのものは変えない。

### 3.4 確認の方法（G4b）
- ボスの絵は、プレビュー画面（今の `tools/preview-enemies-*.html` と同じ形）で、ポーズ・段ごとに見せる。
- 背景は段ごとの静止画を見せる。

## 4. 曲と効果音（ブラウザ上の合成）

### 4.1 曲
| 曲 | 使う場面 | 作り方 |
|---|---|---|
| 舞台裏 | 最深の間への入場 | 低い持続音と、綱がきしむ音。遠くでオルゴールの主題が一度だけ |
| **繰り手との対決** | 戦闘 | 段ごとに重ねる：①低い太鼓（和太鼓に近い合成音）と、うねる低音の繰り返し ②オルガン風の和音とコーラス風の音 ③タイトル曲・野営地の曲の主題を短調・速いテンポで全奏。糸をはじく音をリズムに混ぜる |
| 絵巻 | 序の巻・終の巻 | タイトル曲のオルゴールの主題。終の巻は長調・全楽器の版で終わる |

- 段の切り替えでは、曲を止めずに楽器を足す（今の曲の切り替えはフェードなので、「重ねる」仕組みを曲の側に足す）。
- **決着の瞬間**：曲を止めて無音 → 糸が切れる音が三つ → オルゴールが一節だけ → 終の巻へ。

### 4.2 効果音（新規）
糸を張る（はじく音）／糸を断つ（弦が切れる音・高い音）／三本断ち（三つの切れる音が和音になる）／吊り上げ（綱が巻き上がる）／落とし（太鼓と木の衝撃）／面のひび／幕が落ちる（重い布）／劇場が崩れる（木がきしむ・割れる）／絵巻の筆の音／落款（印を押す音）。

### 4.3 確認の方法（G4b）
- 曲と効果音は、試聴用の画面で段ごとに鳴らして確かめる（今の `SD.Audio.render` を使う）。音量は効果音が曲に埋もれないこと（今のつり合いのまま）。

## 5. 絵コンテ（戦い）

| 場面 | 内容 | 尺（初回／2回目以降） |
|---|---|---|
| 入場 | 幕が上がると、空っぽの舞台裏。吊りランプが揺れ、三人が歩いて入る。題字「最深の間」 | 4秒／1秒 |
| 登場 | 天井から金の糸が三本降りて三人の頭に付く → 幕の奥から二本の手が降りる → 垂れの陰で面の目が光る。題字「深淵の繰り手」 | 8秒／2秒 |
| 糸の段 → 面の段 | 手が幕の垂れを引き落とす。面が全身を現す。曲に和音とコーラスが加わる | 4秒（毎回） |
| 面の段 → 終幕の段 | 奥の書き割りが裂け、逆さに廻る灰輪の影。額縁にひび。秒読みの蝋燭が3本灯る | 4秒（毎回） |
| 三本断ち | 三人の糸が順に弾け、手が跳ね上がる。秒読みの蝋燭が灯り直す | 1.5秒 |
| **決着** | 最後の一撃でスローモーション → すべての糸が順に切れる → 手が落ちる → 面が金継ぎに沿って割れる → 劇場の額縁が外へ倒れる → 無音 → オルゴール → 幕が下りる → 終の巻 | 10秒（毎回。飛ばせる） |
| 倒れたとき | 糸が三人を吊り上げ、人形のように力なく揺れて幕が下りる | 3秒 |

- どの演出も入力で飛ばせ、Shift で早送りできる（GDD §9 の決まり）。
- 入場・登場の長い版は、最初の1回だけ。

## 6. 絵巻（序の巻・終の巻）

### 6.1 共通の作り
- 幕が上がると、横長の巻物が舞台いっぱいに広がり、**右から左へ**ゆっくり流れる（絵巻と同じ向き）。
- 場面は墨の切り絵。灯り・残り火・糸だけに色がある。語りは縦書きで、1場面1行。
- クリックで次の場面へ。いつでも飛ばせる（飛ばしても次から同じ扱い）。タイトル画面に「絵巻を見る」を置き、見返せる。
- 曲は「絵巻」（§4.1）。

### 6.2 序の巻（初めてゲームを始めたとき、約60秒）
- 新しいセーブで「はじめる」を押したとき（音を鳴らせる最初の操作の後）に流し、終わると最初の挑戦の幕が上がる。

| 場面 | 絵 | 語り（案） |
|---|---|---|
| 1 | 夜の野営地。焚き火と、三つの石の筒の灯輪 | 祈れば、灯輪は廻る。 |
| 2 | 深淵へ続く階段と、底で逆さに廻る灰輪 | 深淵の底で、灰輪の主が運命を逆さに廻している。 |
| 3 | 灯を掲げて降りる三人。頭上にうっすら金の糸（気づく人だけ気づく伏線） | 三人は灯輪を背負い、降りていく。 |
| 4 | 倒れた者の残り火が、灯輪へ還っていく | 倒れても、残り火は灯輪へ還る。 |
| 5 | 巻物の終わりは白紙。風で巻き戻り、幕が下りる | （語りなし。白紙が映るだけ） |

### 6.3 終の巻（B17 を倒したとき、約2分）

| 場面 | 絵 | 語り（案） |

### 11.2 確認1：再演1回で複数の糸が断てるか → 断てると「毎回再演」になる
| 規則 | 糸を断った割合 | 再演で断った糸 | 三本断ちのうち再演1回で成立 | 勝った戦いで「受け入れ」も使った |

| 4a のまま（再演でも断てる、終幕は毎ターン3本） | 94〜100% | 断った糸のほとんど | 279 回中 279 回 | 10% |

### 11.4 確認2：断つ・受け入れるの両方に利点があるか（見直し案）
| 段 | 断った | 受け入れた | 受け入れのうち、断てたのに選んだ | よくあるターン |

## 12. 段階4b の実装（2026-10-09） — 採用した規則、明確化、画面、確認

### 12.1 採用した規則
- §11.6 の見直し案を採用（2026-10-09、ユーザー承認）。終幕の段の境は 30% のまま。終幕の段が短すぎるかは、4c（絵・曲・演出）の後に実際に遊んで判断する。
- 数値：HP 1600、段の境 60%・30%、反動 20／本、三本断ち +80、必要な本数 3（`SD.Data.THREADS`）。試作用の切り替え（環境変数・選択肢）は片づけ、この規則だけを残した。

### 12.2 明確化した点
**(1) 累積の数え方**
- 秒読みのコマ（秒読み・三／秒読み・二／最後の糸）のターンに、自分の手で断った糸を1本ずつ数える。
- **同じリールの糸を、別のターンにもう一度断っても数える**。1ターンのうちに1つのリールに張られる糸は1本なので、同じターンに同じリールで2回は数えない。
- 3本に届いたターンが三本断ち。届いた時点で余った分（例：2本たまった状態で2本断つ）は持ち越さない。
- 数えないもの：台本送りで外れた糸（断っていない）、糸の段・面の段で断った糸、終幕のターン（糸がない）。最後の糸から終幕へ台本を送った場合、そのターンに断った糸は数えず、終幕が行われて数は0に戻る。

**(2) 「三人の糸が切れる」決着の演出との整合**
- 三本断ちは「どのリールを断ったか」ではなく「秒読みの間に何本断ったか」で決まる。そこで画面では、数を**三人とは別の3本の糸**で示す（HP バーの下の「三本断ち」の3つの印）。1本断つごとに1つずつ切れる。
- 3つ目で三本断ちになった瞬間、どのリールを断ったかに関係なく、**三人の頭上の糸（§3.3）が3本とも順に弾ける**（三人が同時に自由になる）。秒読みが3に戻ると、繰り手が糸を張り直す。
- 繰り手は三本断ちのターンにしか倒れないので、§5 の決着の演出（すべての糸が順に切れる → 手が落ちる → 面が割れる）は、どの勝ち方でも同じ流れで成り立つ。
- 三人の頭上の糸の絵と、切れる演出は 4c で作る。4b では HP バーの下の印と、「三本断ち」の大きな文字・金の光で示している。

**(3) HP 1 で倒れない理由の伝え方**
| 場所 | 表示 |
|---|---|
| HP バー | 左端に金の結び目と「とどめは三本断ちだけ（HPは1で止まる）」。HP 1 のときは「糸で吊られている — 三本断ちでとどめ」が点滅する |
| 予測パネル（発動前） | 倒せる量でも三本断ちでなければ「敵HP 4 → 1」と「**倒しきれない**：糸で吊られていて HP 1 で止まる。とどめは三本断ちだけ（あと n 本）」。敵の番の燃焼・棘で 1 になるときは「敵の番の後 1 … 糸で吊られて 1 で止まる」。三本断ちで倒せるときは「**三本断ちでとどめ！**」 |
| 止められた瞬間 | 繰り手の上に「糸で吊られている／三本断ちでしか倒れない」（1ターンに1回） |
| 左パネル（回す前） | 「とどめは三本断ちだけ（HP は 1 で止まる）」。終幕の段では「三本断ち n/3」も並べる |
| 自動発動 | 「この発動で倒せる」ときの自動発動は、吊られて倒れないときには行わない |

**(4) HP 1 になってから決着までのターン数**（sim、全灯紋・入口①、745 戦）
| 指標 | 結果 |
|---|---|
| HP 1 で吊られた戦い | 49%（勝った戦いの 66%） |
| 勝った戦い：吊られてから三本断ちまで | 中央値 **1 ターン**（次のターン）、p90 2、最長 7。1 ターン以内 78%、2 ターン以内 91% |
| 負けた戦い：吊られた後に倒れた | 負けの 26%（多くは吊られた同じターンの終幕） |
| 吊りで止められたダメージ（止まったターンの量） | 中央値 51、p90 448 |

- 過度な引き延ばしにはなっていないと判断する。ただし、大きな一撃が吊りで止められる場面（p90 448）の手応えは、G5 の通しプレイで確かめる。

**(5) リセットの規則**
- 数が 0 に戻るのは2つの場合だけ：
  - ① 三本断ちが起きたとき（どの秒読みのコマでも）。秒読みは「秒読み・三」に戻り、最後の糸のターンなら終幕は台本から消える。
  - ② 終幕が行われたとき（借り火の「借りの一手」で行われた場合も）。秒読みは次の「秒読み・三」から。
- 終幕の段に入ったときは 0 から始まる。①②はどちらも単体テストで確かめている（下の 12.4）。
