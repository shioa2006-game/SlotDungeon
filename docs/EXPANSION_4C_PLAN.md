# 段階4c 計画 — 深淵の繰り手の絵・最深の間・曲・演出（2026-10-10）

前提：戦いの規則は「四本の糸」で決まり（[EXPANSION_4B_PROMISE.md](EXPANSION_4B_PROMISE.md)）。見た目・音・絵コンテの方向は [EXPANSION_4A_SPEC.md](EXPANSION_4A_SPEC.md) §3〜§5（G4 で合意）。ここでは、それを四本の糸に合わせて直し、作る順番と確認の区切りを決める。規則と数値は変えない。

## 1. 四本の糸に合わせて直すこと
| 4a の案 | 4c で作るもの |
|---|---|
| 三つの段（糸／面／終幕） | 四つの段：**糸の段**（手と操り板だけ。面は闇の上で目だけ光る）→ **面の段**（幕の垂れが落ち、面が姿を現す）→ **祈りの段**（面の下に黒い紙の着物の胴が現れる。袖の裏に、これまでのボスの小さな人形が吊られている）→ **終幕の段**（面のひびが広がり、目が燃え、奥の書き割りが裂ける） |
| 操り板から三人へ三本の糸 | 操り板から**四本**の金の糸。切れた糸は板から垂れて揺れる（約束の「切れた糸は垂れて消える」） |
| 段が変わると楽器を足す（3段） | 4段で重ねる：①太鼓とうねる低音 ②オルガン風の和音 ③祈りの段：鐘とコーラス風の音（トトの段） ④主題を短調・速く全奏 |
| 決着：三本の糸が切れる | 最後の糸が切れる → 手が落ちる → 面が金継ぎに沿って割れる → 額縁が倒れる → 無音 → オルゴール |

## 3. 作り方の決まり
- 絵は今と同じ手続き的な描画（`SD.Art`、切り絵劇場の作法：紙・真鍮・金の糸。加算の光は灯りと糸だけ）。
- 曲は今と同じブラウザ上の合成（`SD.Audio`）。段で楽器を足す仕組みは、曲の側に新しく足す（ほかの曲の鳴り方は変えない）。
- 演出は今の演出の流れ（`director.js`）に足す。ほかの敵の演出は変えない。
