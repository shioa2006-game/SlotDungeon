## 4d-1・4d-2 で決めた細部
- 記録の印（セーブ）：`stats.finalRuns / finalClears / finalFalls / finalBestTurns / firstFinalClear`、`seen.treeComplete`、`seen.b17Notice`。
- 入口①から B17 に挑んだ挑戦：本編（灰輪の主）と灰の底の分は、それぞれ決まった時点で書く。B17 の分は終わったときに `Meta.applyFinalResult` で書く。倒れても、それまでの記録は失わない。
- 入口②（最深の間へ）の挑戦は、B17 の記録だけが付く（挑戦・勝利・死亡などの本編の記録は付かない）。
- シミュレーターのボットは「最深の間へ」を選ばない（B1〜B16 の出力は変わらない。判断の回数にも数えない）。
- 確認用の入口：`?test=camp`（最後の灯紋が1つ残ったキャンプ。`&keeper=0` で灰鐘の番人の撃破前）。`最終ボスを試す.html` からも開ける。

## 4d-3 で決めた細部
- `js/game/scroll.js`：巻物が右から開き、右から左へ読む。墨の切り絵（三人と繰り手は今の絵を墨一色の影絵にしたもの）で、灯り・残り火・糸だけに色。語りは縦書きで、1列10字で折り返す。クリックで次の場面、「とばす」（Esc）で終わる。
- 序の巻：①野営地「祈れば、灯輪は廻る。」②深淵への階段と逆さに廻る灰輪「深淵の底で、灰輪の主が運命を逆さに廻している。」③灯輪を背負って降りる三人（頭上にうっすら金の糸）「三人は灯輪を背負い、降りていく。」④倒れた者の残り火が灯輪へ還る「倒れても、残り火は灯輪へ還る。」⑤白紙。巻物が巻き戻る。
- 終の巻：①序の巻を速く流し直す（灯紋はすべて灯り、灰輪は正しく廻り、糸はない）②白紙に筆で描き足される最深の間（四本の糸が断たれている）「糸は断たれた。」③三人が自分の手で灯輪を廻す「運命は、祈るものではなく、組み立てるものになった。」④夜明けの野営地「灯輪は、もう誰の糸にも繋がれていない。」（曲が長調に）⑤題「灯輪と深淵」と落款、奥書（挑戦・灰の底・真のクリアの回数、灯した灯紋、集めた残り火、遊んだ時間）、「完」。クレジットは載せない（ユーザーの決定）。
- 遊んだ時間：`profile.clock`（秒）。この版より前のセーブでは、数え始めた日付を奥書に添える。
- 記録の印：`seen.prologue`、`seen.epilogue`。
- 確認用の入口：`?test=emaki`（タイトル画面から両方の巻を見られる）。
