# 拡張の基準値（段階1） — 初クリア後の新区間に向けて

2026-10-08。ゲーム本体は変更していない（`tools/sim.js` に計測モード `baseline` を追加しただけ）。既存の sim の出力は全モードで変更前と完全一致。

---

## 0. 段階0で決めたこと（目的と制約）

| 項目 | 決定 |
|---|---|
| 目的 | **初クリア後に開く新区間**（新しい階層と新しい敵）を作り、残ったスキルツリーを使い切る場にする。ツリーを伸ばすほど新区間を攻略しやすくなるようにする |
| 増やす場所 | 新しい戦闘・新しい敵は、主にクリア後の新区間に置く。クリア前（B1〜B12）には足さない |
| 新しい敵の範囲 | 新しい階層ごとの追加も可 |
| 制約1 | 初クリアまでの体験（B1〜B12・灰輪の主・灯紋の価格・勝率の曲線）は変えない。sim の run1 とボス8キットの出力が、毎回変更前と一致すること |
| 制約2 | 段階的に進める。1段階＝新しい層1つ（通常の敵2種＋エリート1体程度）。段階ごとに sim と Dots で検証してから次へ |
| 制約3 | 新しい敵は、強い構成でも消えない「問い」を持つ（HPを増やすだけにしない） |
| 制約4 | 新しい灯紋・台本操作は、必要が明確になるまで足さない |

---

## 1. 計測の方法

```bash
node tools/sim.js baseline <strategy> 40
```

- strategy は balanced、valor、hearth、weave の4種で、それぞれ40本のキャンペーンを実行した。
- 新しいセーブから始め、初クリアの後も続けて遊ぶ。ツリーが全部灯った後、さらに5回挑戦してから止める。
- `BASELINE_JSON=path` を付けると、戦闘ごとの生データを保存する。
- **初クリアまで**：ボットのノード購入は既存の `campaign` と同じ。そのため数値も既存と一致する。
- **初クリア後**：ボットは方針の順でノードを買い、方針の一覧が尽きた後は、届く中で一番安いノードを買う（ツリーを埋めるプレイヤーを想定）。
- 挑戦の開始は、解放済みの一番深い近道（B5）。
- 戦闘ごとに記録した項目：

| 項目 | 意味 |
|---|---|
| ターン数 | その戦闘にかかったターン |
| 1ターン撃破 | 1ターン目で倒したか |
| 1ターン目の与ダメ／敵の最大HP | 選んだ出目で1ターン目に与えるダメージ（予測値）を、敵の最大HPで割った値。**成長の余裕**を表す |
| 判断ターン | 実際のゲームなら自動発動せず、プレイヤーの操作を待つターン（`shouldAutoResolve()` が false） |
| 負け | パーティが全滅した戦闘の割合 |

- 時間は、既存の sim の時間モデルによる見積もり（人間の実測ではない）。

## 3. Dots の観察との対応

| Dots の観察 | sim |
|---|---|
| 初クリア時に22ノード未購入 | 残り21〜23ノード |
| R6以降、ボス前の7戦がすべて1手 | 初クリア後の通常の敵の1ターン撃破は 44〜77%（ボットは Dots より操作が下手なので、控えめな値） |
| R12〜15、ボス前の23戦がすべて1手 | 全部灯った後の1ターン撃破は 90% |
| 衛兵・僧・鏡で台本の価値が出た | 初クリア後も、台本のある敵が相対的に粘る |

sim の数値は**下限**として読む。人間の上手なプレイヤーは、ボットより早く倒す。

## 4. 段階2の設計に使う数値（仮の目安）

1. **「もったいない」の正体**
   - 残ったツリーが手に入らないわけではない。約30分で全部灯る。
   - 問題は、**その先に、ツリーを必要とする相手がいないこと**。全部灯った後は勝率100%、通常の敵の9割を1ターンで倒す。
   - 新区間は「ツリーを灯す理由」と「灯したツリーを試す場」の両方になる必要がある。
2. **新区間の難しさの目安**
   - 全部灯った構成でも、通常の敵が平均2〜3ターン、エリートが4ターン前後、新しいボスが8ターン以上かかるくらい。
   - 今の全成長構成は、1ターン目に通常の敵の最大HPの約1.5倍を与える。**HPだけで2〜3ターンにすると、今の通常の敵の4〜5倍のHPが要る。** それよりも、ダメージを1ターンで通しきれない規則（封印・反射・固定・台本）で長さを作るほうが、制約3に合う。
3. **入れる時期と勝率の上がり方**
   - 初クリア直後（ツリー約40〜45%）の構成では勝率が低い。全部灯った構成では勝率が高い。ただし100%にはしない。
   - 目安（段階2で決める）：初クリア直後 10〜20%、全部灯った後 60〜80%。
4. **残り火の扱い**
   - 新区間で残り火を稼げると、ツリーが30分より早く埋まり、新区間の寿命が縮む。
   - 新区間の報酬は、残り火以外（新区間の進捗・記録など）にするか、量を抑える必要がある。段階2の論点。
5. **時間**
   - 今の1回の挑戦は約4〜5分（B5から）。
   - 新しい層1つ（通常の敵2〜3戦＋エリート）を足すと、1回あたり +2〜3分程度の見込み。

## 5. 限界

- ボットは人間（Dots）より操作が下手。1ターン撃破率は低めに出る。
- 「判断ターン」は**UIが止まる回数**で、判断の**質**ではない。全部灯った後も、ほぼ全ての戦闘で1回は止まる。ただしその中身は「既知の解き方の1手」であることが多い（Dots の C 評価）。判断の質は Dots のプレイで見る。
- 時間は sim の見積もりモデルで、人間の実測ではない。
- 初クリア後のノードの買い方（方針の順 → 安い順）は1つのモデルにすぎない。
