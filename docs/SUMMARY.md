# EMBERWHEEL ― 灯輪と深淵 — 提出サマリー

## 1. ゲームタイトル
**EMBERWHEEL ― 灯輪（ともしわ）と深淵**

## 2. 一文説明
三人の小さな探索者が運命装置「灯輪」を回して深淵へ挑み、倒れるたびに持ち帰った残り火で灯輪に新しい操作を灯し、**祈るだけのスロットを、自分で組み立てる運命へ育てていく** Run型スロット・ダンジョンRPG。

## 3. Core Loop
野営地で灯紋（恒久スキル）を灯す → 降下 → 1階層1部屋の戦闘（SPIN → ずらし/留め/再演などで介入 → 発動 → 敵の予告行動）→ 勝利ごとに「分かれ道」（刻印3択＝リールを彫る＋次の扉＝リスク選択）→ 倒れたら残り火を全額持ち帰る → 死亡画面の「運命のささやき」が次に灯すべき灯紋を1つ示す → 1キーで灯して再挑戦。

## 4. 「あと1回」を生む仕掛け（5つ）
1. **見えている惜しさ → それに答える最初の灯紋**: 発動列の上下も常に見え、1コマずらせば三連のマスが光る（「惜しい！」）。Run 1 中に一度だけ無料で“ずらし”を体験させ、最初の灯紋【押し手】がまさにそれを買う。
2. **運命のささやき**: 死亡画面で、このRunの実データから「ずらせば三連になった目が5回」「封印が2つ残ったまま倒れた」等の後悔を1つだけ示し、それを解決する灯紋と【灯して再挑戦】ボタンを並べる（序盤〜終盤まで対応）。
3. **あと少し**: エリート/ボスのHPバーに自己ベストの印、死亡画面に「残り22/72 — あと少し！」。健闘分の残り火も支払う（死亡ペナルティなし）。
4. **Run中の「次の灯紋」トラッカー**: 画面右上に次の灯紋までの残り火。到達した瞬間「今倒れても【再演と留め】を灯せる」と鳴る。
5. **新しい動詞を試したくなる導線**: 灯した直後の降下ボタンは「【再演と留め】を試す」、次のRun開始時に新しい灯紋のバナーと1行ヒント。

## 5. Slot System
- 3本の石の円筒（各10コマ前後のストリップ）。表示は3段、**中央の発動列**の目が三人の行動になる（剣=ブラムの斬撃、焔=ルゥの鎧無視の火球、癒=トトの回復、盾=ブロック、灯=残り火と火種、髑髏=呪い、星=最適な記号に化ける）。
- **一致倍率** 1/1.5/2.5（三連は単発の7.5倍）。三連で各記号の特殊効果、**絆の陣**（リール1剣・2焔・3癒＝各自の目が各自の持ち場に）で全効果×3。
- **介入**（灯紋で段階解放・火種を消費）: ずらし（上下のマスを押す）→ 留め（2本まで）＋再演 → 継ぎ留め（次ターンへ持ち越し）→ 遠押し（2コマ）→ 写し身（ある目を別リールへ写す）→ 運命の鍵（好きなコマを選ぶ）。トトの祝福（髑髏→癒）。
- 火種: 2で開始（上限3〜4）、勝利・灯・三連/絆で回復 →「今使うかボスまで残すか」。
- **確率空間そのものを育てる**: 毎勝利の「刻印」でリールに記号を彫る/削る/変換/金箔。選択肢には「そのリールの剣 30%→36%／剣の三連 2.7%→3.6%」のように確率変化を表示。各リール横のリボンで全コマが常に見える。
- 予測パネル: 発動前に与ダメ→敵HP、被ダメ予測（ブロック・反射込み）、再演時の三連/絆確率。

## 6. Skill Tree（灯紋の輪・35ノード）
- **運（操作）**: 押し手→再演と留め→手慣れ・継ぎ留め→遠押し→写し身→運命の鍵／火種壺→星の欠片・鑿・精妙。**運に翻弄される→運を組み立てる**主軸。
- **猛（火力とコンボ）**: 研ぎ→絆の陣→追撃・処刑人→双の誓い・三連の極意→連鎖（三連の後にもう一度回る）／燎原（燃焼）→灰燼・髑髏の契約（呪いを力に変える）。
- **守（生存）**: 外套→焚き火・棘の盾→祝福・起死回生・蓄え→背水・不屈→守護の誓い（盾の三連で最大の一撃を跳ね返す）→灯守り。
- 橋渡し: 分かれ道（扉3択）、賭博師の目、祈りの手、血の代価。
- 主要ノードの多くは**操作・ルール・確率空間**を変える（数値ノードは研ぎ・外套・火種壺・不屈・双の誓い・三連の極意のみ）。霧で段階的に見せる。

## 7. Incremental Progression
| Run | 解放 | 同じスロット画面を見て考えていること |
|---|---|---|
| 1 | なし（目覚めの1回だけ） | 「いい目出ろ」「上の段に剣…惜しい！」 |
| 2 | 押し手 | 「光ってる、押せば三連」「火種は犬まで残す？」 |
| 3–4 | 再演と留め・絆の陣 | 「ペアを留めて1本だけ回す（30%）」「剣・焔・癒を各自の持ち場に」 |
| 5–8 | 燎原/棘/継ぎ留め/鑿/星 | 「この敵は鎧持ち、焔が欲しい」「強撃の前に盾を継ぎ留め」「灯を削って剣を彫る…でも封じが来る」 |
| 9–13 | 写し身/運命の鍵/連鎖/守護 | 「封印用に火種3を温存して深淵へ」「鍵で確定三連」 |
第二層ショートカット（犬を一度倒すと解放、スキップ分の刻印と遺物を受け取る）で後半Runの冗長さを削減。

## 8. Boss「灰輪の主」
灯輪の逆廻りの双子。巨大な灰の歯車と仮面。
- **第一段階 三つの封印**: 封印が残る間ダメージ25%。**三連・絆**でしか割れない（燃焼・棘/守護の反射・死神は封印無視）→ 狙って揃える操作力か、別系統の解答を要求。
- **第二段階 逆廻り**: 毎ターン封じる記号が 剣→焔→盾→癒 と巡る（次も見える）→ ずらし/再演で禁じ手を外しながら殴る。
- **第三段階 破滅の秒読み**: 3→2→灰燼（36）→ 盾を積むか、温存した火種で削り切るか。
- **封印中は灰輪が毎ターン加速**し、封印の陰で削り続けることはできない（燃焼・反射も封印越しは半分）。
- 検証（上手いボット）: Run 3相当 0% / 標準的な17ノード 24% / 運・猛・守の特化 23〜36% / 精通25ノード 95%。**同じ25ノードでも介入しなければ1%** — 数値の壁ではなく「揃える技術」の関門。

## 9. Art Direction「灯火の切り絵劇場」
- **世界観**: 地の底で逆さに廻る灰輪と、それを止めに降りる灯輪。全ては玩具の劇場の舞台で演じられる。
- **ビジュアル**: 舞台を額縁と幕の垂れで縁取り、灯輪が舞台のフットライト。死ぬと幕が下り、死亡画面は幕に印刷される。
- **キャラクター**: 太いインク輪郭＋フラット塗り＋影1段のパペット。ブラム（バケツ兜と赤い羽根）、ルゥ（帽子の先に蝋燭が灯る魔女）、トト（香炉を揺らす丸い僧）。待機・歩行・攻撃・詠唱・祈り・防御・被弾・歓声・介入ジェスチャー・倒れの全ポーズ。
- **敵**: 蝋燭を背負うネズミ、鐘を下げた猟犬、髑髏紋の蛾、写し鏡の影、歯車ゴーレム、灰輪の主…シルエットと色で判別、溜めや構えは姿勢で予告。
- **Slot**: 真鍮と黒石の運命装置。骨色の石円筒、金の発動列、上に火種の蝋燭、右にレバー、灯紋の数だけ縁のルーンが灯る。
- **UI**: 黒い石板に真鍮の縁。見出しは Kaisei Decol、UIは Zen Maru Gothic。
- **色**: 藍と紫の闇に蝋燭の暖色。記号色（剣=鋼白・焔=橙・盾=空色・癒=翠・灯=金・髑髏=紫）は予約色として背景では使わない。層ごとに暖色の地下蔵→青緑の納骨堂→銅と炉火の歯車深淵→灰と黒炎の座。

## 10. プレイテスト
docs/PLAYTEST.md に詳細。要点:
- **最初の版で面白くなかったこと**: Run 1 のエリートに Spin だけで99%勝てて「あと少し」が起きない／最初の解放（全リール再演）が運ゲーのまま／火種が少なく大半のターンが自動／無順序の絆＋ずらしが唯一解でボスが1ノードで解ける／第二層が緊張感なし／操作系ビルドだけボスに勝てない。
- **変更**: エリートと第一層の再調整、最初の灯紋をずらしに、火種収入の追加、絆を順序付き陣形に、第四輪の削除と運命の鍵、第二〜三層の強化、精妙の追加と猛/守の調整、ショートカットの整理、ボスの段階移行の予告一致、反射込みの予測、Run中の次の灯紋トラッカー、狙い目ヒント 等。
- **結果**: Spinのみ Run 1 は約72%がB4で倒れ、犬の残りHP中央値≈28%（あと少し）、所要≈2分、99%以上のプレイヤーが Run 1 で三連を体験。上手いボットで7〜9 Run・現実的な時間モデルで約31〜35分（人間は40〜55分想定）でボス撃破、運/猛/守/均等/ランダムの全戦略でクリア可能。エンジンのファズ 5,000 Run で不変条件違反 0。

## 11. 起動方法
`index.html` をブラウザ（Chrome/Edge）で開くだけ。もしくは `node tools/serve.js` → http://localhost:8080 。操作は Space（回す/発動）、マスのクリック（ずらし/留め）、R（再演）。
